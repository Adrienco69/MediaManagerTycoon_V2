# Media Manager Tycoon V2

Première base Godot 4 du projet.

## État actuel

- Projet Godot initialisé.
- Scène principale lançable : `scenes/main.tscn`.
- État global : `scripts/game_state.gd`.
- Départ à 1 200 CC.
- Calendrier de 364 jours / 52 semaines.
- 7 mois fictifs : Floréal, Clôture, Crépuscule, Zénith, Origine, Essor, Brumal.
- Mois de 7 ou 8 semaines selon le calendrier validé.
- Vitesses de temps :
  - Heure : 10 secondes réelles = 1 heure de jeu.
  - Jour : 20 secondes réelles = 1 jour de jeu.
  - Semaine : 30 secondes réelles = 1 semaine de jeu.
- Navigation de base : Notre groupe, Grille TV, Zap'Chaine, Productions.

## Prochaine étape

Créer le démarrage réel de partie : groupe du joueur, première chaîne, MMTN initiale et première grille programmable.
